📁 Subir Documento de Vuelo
Sube aquí la documentación oficial que el Centro de Control o el proveedor de Load Control de Viva Aerobus entrega al equipo de tierra para preparar, cargar, despachar y cerrar el vuelo de forma segura. Los campos se adaptan según el tipo de documento, y si configuras tu API key de Claude puedes pedir que la IA lo lea y extraiga los datos automáticamente.
🤖 Configuración de Análisis con IA (Claude)
⚠️ Tu API key se guarda solo en esta sesión del navegador (se borra al cerrar la pestaña) y las llamadas a Claude se hacen directamente desde tu navegador. No la uses en equipos compartidos ni la compartas. Para un despliegue en producción, lo más seguro es que el análisis pase por tu backend (Apps Script) en vez de exponer la key en el cliente — con gusto te ayudo a moverlo ahí cuando quieras.
Sin configurar — el análisis con IA está deshabilitado.
